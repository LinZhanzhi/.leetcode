we want to get this expression

$$\max_{0 \leq i, j < n} |arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|$$


and we can find that arr1 and arr2 is independent
even we can think of there is a new array arr3[i] = i, and we want to get the maximum of
$$\max_{0 \leq i, j < n} |arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |arr3[i] - arr3[j]|$$

so there must be a general algorithm for when the number of arrays scale.

let's investigate when k = 1

let's find a way to find out
$$\max_{0 \leq i, j < n} |arr1[i] - arr1[j]|$$
it equals to
$$\max_{0 \leq i, j < n} \max(arr1[i] - arr1[j], arr1[j] - arr1[i])$$
which is equal to (introduce a sign variable s1)
$$\max_{s1 \in \{-1, 1\}} \max_{0 \leq i, j < n} s1 * (arr1[i] - arr1[j])$$
which is equal to
$$\max_{s1 \in \{-1, 1\}} \max_{0 \leq i, j < n} (s1 * arr1[i] - s1 * arr1[j])$$
which is equal to
$$\max_{s1 \in \{-1, 1\}} (\max_{0 \leq i < n} s1 * arr1[i]) - (\min_{0 \leq j < n} s1 * arr1[j])$$

the time complexity of this is O(2 * n) = O(n), which is acceptable for n <= 40000

for k = 2, the original expression, which is :
$$\max_{0 \leq i, j < n} |arr1[i] - arr1[j]| + |arr2[i] - arr2[j]|$$
can be rewritten as (introduce two sign variables s1 and s2)

$$\max_{s1, s2 \in \{-1, 1\}} \max_{0 \leq i, j < n} s1 * (arr1[i] - arr1[j]) + s2 * (arr2[i] - arr2[j])$$
which is equal to
$$\max_{s1, s2 \in \{-1, 1\}} \max_{0 \leq i, j < n} (s1 * arr1[i] + s2 * arr2[i]) - (s1 * arr1[j] + s2 * arr2[j])$$
which is equal to
$$\max_{s1, s2 \in \{-1, 1\}} (\max_{0 \leq i < n} (s1 * arr1[i] + s2 * arr2[i])) - (\min_{0 \leq j < n} (s1 * arr1[j] + s2 * arr2[j]))$$

the time complexity of this is O(4 * n) = O(n), which is acceptable for n <= 40000


so for k = 3, the original expression, which is :
$$\max_{0 \leq i, j < n} |arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |arr3[i] - arr3[j]|$$
can be rewritten as (introduce three sign variables s1, s2 and s3)
$$\max_{s1, s2, s3 \in \{-1, 1\}} \max_{0 \leq i, j < n} s1 * (arr1[i] - arr1[j]) + s2 * (arr2[i] - arr2[j]) + s3 * (arr3[i] - arr3[j])$$
which is equal to
$$\max_{s1, s2, s3 \in \{-1, 1\}} \max_{0 \leq i, j < n} (s1 * arr1[i] + s2 * arr2[i] + s3 * arr3[i]) - (s1 * arr1[j] + s2 * arr2[j] + s3 * arr3[j])$$
which is equal to
$$\max_{s1, s2, s3 \in \{-1, 1\}} (\max_{0 \leq i < n} (s1 * arr1[i] + s2 * arr2[i] + s3 * arr3[i])) - (\min_{0 \leq j < n} (s1 * arr1[j] + s2 * arr2[j] + s3 * arr3[j]))$$
the time complexity of the above expression is O(8 * n) = O(n), which is acceptable for n <= 40000
